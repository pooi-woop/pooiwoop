实习第三个月总结：从 AI 助手到 β 智能体引擎的系统重构、托管运营与线上稳定性攻坚

署名说明：在 xlagent 仓库中 hym / heyiming / Heyiming / wenhai03 均为本人提交（此前部分提交署名不统一，wenhai03 也归本人）；e-commerce 前后端里同事 why、xiewenhai 的提交不计数。

归属 仓库 类型 本窗提交量

合计约 133 次提交。 这一个月的主线非常聚焦：把「AI 助手」从单会话问答，重构升级为一套带自主循环、工具调用、任务托管与防护兜底的智能体引擎（α引擎 → β引擎），并把真实设备、发布、克隆、日报、热搜等 32 个业务能力接入工具面，逐条落地到生产。

一、xlagent —— 本月主战场：α 引擎 → β 引擎

这是本月投入最深、提交最密的仓库，一路从「浏览器自动化 + 托管编排」长成了自研起的智能体引擎生态。

1.1 月初：浏览器自动化与托管编排起量

  • 接入 IM webhook（飞书 & 企业微信机器人），自动化报表推送、任务创建优化（R100–R114 批次）。
  • 25 轮「自主 Loop」快速迭代：创建任务先设备后类型、养号参数阶段爬坡、中文时间窗任务查询、通用取消与会话重置、发布回调确认、托管裁剪。
  • 设备链路提速、长期记忆召回、完成通知健壮性、克隆源改造、飞书卡片渲染、画像完成度。

1.2 托管运营体系初成

  • 管控配置改版：配额合一、发布策略下线、窗口画像驱动、预算护栏、AI 语言跟随目标市场。
  • 日报/热搜推送：克隆门槛 + 多热点 + 数据驱动 fan-out；自动化定时任务与托管派工、能力路由、克隆发布链、积分查询等批量更新。
  • 发布源列表修复、托管视频逐条审核/来源发布、托管配置停用时仍执行的修正。

1.3 分水岭：β 引擎重构（9/18–9/19）

  • 从零搭起 xlagent-beta 地基：agentcore 内核（工具注册表 + LLM 工具调用循环 + 流式）+ mcpkit（MCP stdio/HTTP 双传输 + 外部挂载）+ agenttools（16→32 个全真数据工具）+ /api/v1/beta/* 端点 + 独立 cmd/xlagent-mcp 进程，全仓 27 个包测试绿。
  • 分多批交付（第 5~61 轮）：五域服务真实现、工具面 32 全真数据（模拟降级退役）、app 层 6 工具、task_submit 三重闸、guard_diagnostics、深搜限界、视频 SQL 全量聚合；配套八层验收矩阵（28 包 / E2E 21 用例 / 真 LLM 流式 / SSE 线级 / stdio 28 工具 / 一键脚本）。
  • 将 β 工具优先引擎并入主线（agentcore 工具循环 + 32 工具 + MCP stdio + beta 端点 + task_submit 三重闸）。
  • β 对话流式思维链兜底：上游零 reasoning 增量时补发说明事件，根治前端思考流整轮空白。

1.4 守卫看护体系（中旬）

  • 守卫看护：脚本被停/崩溃后自动拉起（看护集合从 EC 守卫任务推导 + 空队列活性探针 + 可重复重建）。
  • 收紧探针窗口（检测从约 4 分钟压到约 2 分钟）、派工路径守卫重建纳入上限+退避。
  • 无回调任务完成推断 + 消费中禁重启闸门（解决队头 running 堵死队列）。

1.5 防护与安全

  • 非托管任务回调凭据闭环 + 设备归属闸 + AIGC 选模 provider/model 成对替换。
  • β 引擎防护体系：检查点/快照/重复调用守卫/工具调度；能力守卫、凭证模块、任务停止与预算可负担性判定。
  • 鉴权账号主键只认 id 类字段并保精度（19 位 bigint 防 float64 科学计数法）+ 积分对账性能优化。

1.6 技能、多模态与上下文

  • 技能体系：官方技能内嵌恒在不可删 + 第三方「来源+哈希锁」；第三方技能 REST API + 对话归档 + @mention。
  • 聊天多模态图片进模型上下文（images 通道 + 预签名重签 + product_image_save 显式入库）。
  • 用户自接 MCP 工具服务器 + @引用业务对象注入。
  • 上下文预算分层：微压缩 + 历史窗口按 token 预算 + 摘要熔断；plan/steer/上下文终结工具与 LLM 用量计量落库。

1.7 收尾：发布素材库 + 文档

  • 文档库与 read_pdf 读取链路、发布素材库（列表/立即派发/TTL 回收）、话题获客参与人互动脚本接口、定时任务允许自动执行（含单测与 apifox 文档）。
  • 发布链路改走平台原「素材库发布」、发布文案带源视频标题、错误文案细化到具体病因。

二、e-commerce-frontend —— 把 β 引擎搬上前台

  • 托管运营面板：仪表盘（每日配置/派工/守卫健康卡与诊断）、任务看板/卡片网格、调度构建器、报告库、任务暂停恢复。
  • agent-chat 强化：β 引擎前端接入（引擎路由 + 轨迹状态）、工具结果结构化预览（kv/trend/list）、思维链重构为 AgentTraceBlock、token 用量展示、插话打断乐观定格。
  • 自动化页重构（9/23）：任务看板/卡片网格/调度构建器/报告库 + @引用补全面板 + xlagentClient 抽取 + 表单卡图片对齐。
  • 素材库 / 文档（9/29 收尾）：文档附件上传与 PDF/Word/表格浏览器内预览、文档库+发布素材库管理页、快捷话术面板改版、卡片按钮改走流式发送。
  • 交互打磨：深色模式、ReasoningBlock 推理依据透出、AutoScroll 优化、上传图片多模态通道。（另有大量同事 UI 优化，不计入本期统计。）

三、e-commerce-backend —— 网关、发布链路与性能

  • 发布链路健壮性：video clone queued-stuck 修复、AIGC video download 同步、material_preview/video_clone 下载与克隆健壮性。
  • 视频克隆与素材：视频克隆算力不足重试与等待重派发、脚本采集表迁移及库表审计。
  • 网关与安全：设备脚本包 302 装不上——网关对带 iec 参数的下载改流式直出（3 条单测 + 事故复盘 + 蓝绿部署文档）；设备配置接口对未登记设备号不再 panic；protoc 补齐 webhook.pb + X-Ingest-Token 上报密钥核查文档。
  • 性能优化：AIGC 素材列表预览按页预载 file 行，消除逐条 N+1。
  • 统计账号规范化：新增 NormalizeTiktokAccount。
  • 支付域/运维：9012 后端蓝绿部署总结（pro2 切流完成）、Fuiou 支付域配置、设备上下线通知、xlagent 部署 SOP、orchestrator 轮询黑洞排查。

四、autodl-orchestrator & back_tk_message_app

  • autodl-orchestrator：归档 AutoDL orchestrator 源码；应用加固补丁（warmup 预算 fail + idle 关机守卫 + GPU 无库存降级）；孤儿实例清理 + warmup 短探针/预算复位；网关鉴权加固——daemon 除 /health 外全部路由要求 X-Gateway-Token（fail-closed）。
  • back_tk_message_app：Dashboard 页面调整与 start.ps1 启动脚本优化。

五、这个月 vs 上个月

维度 上个月 这个月
主题 安全/鉴权主权、托管系统、聚合聊天 AI 智能体引擎系统化（α→β）、托管运营、线上稳定性
主阵地 5 个 Gitee 仓库（公司）+ 7 个 GitHub 模组 D:\hym 下 5 个公司仓库，xlagent 为核心
关键词 HMAC/OAuth/AES、SQL 聚合、QR 登录 agentcore、MCP、工具循环、守卫看护、预算护栏、多模态
风格 做对、做稳、做安全 做出一个「自己会跑又不会失控」的智能体引擎

上月是”把单个功能做对做稳做安全”，这月则是系统性了一次整引擎重构——不只是写一个接口，而是搭起 内核（agentcore）/ 桥接（mcpkit）/ 工具层（agenttools） 三层架构，并给”无人值守自动化”配上守卫、看护、预算与凭证防护。

写在最后

刻意控制篇幅：这一个月最核心的一句话是——AI 从「能回答问题」走到「能自动执行完整业务，且不会因为没人盯着而失控」。从工具注册到流转、从上下文预算到 LLM 用量计量、从守卫看护到设备归属闸，几乎每一项都在回答同一个问题：怎么让自动化在无人时也能安全可靠地跑。蓝绿部署、事故复盘、SOP 文档也成了本月常态。

一点反省：跨仓库 commit 署名本月出现多种写法（hym/heriming/Heyiming/wenhai03），后续应统一命名规范，方便回溯。

下月目标：

  • 把 β 引擎的「发布素材库 / 视频发布链路」与平台原有发布能力彻底对齐收敛
  • 为 agentcore 工具循环沉淀更完整的可观测与预算治理
  • 统一 commit 署名与提交规范

继续加油。
